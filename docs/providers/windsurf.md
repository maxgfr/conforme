# Windsurf (Devin Desktop)

> Cognition's AI IDE, formerly Windsurf, now shipped as Devin Desktop. Source: `--from windsurf`

Windsurf was renamed Devin Desktop in v3.0.12 (2026-06-02). Since v3.6.21
(2026-07-29) new tabs default to the **Devin Local** agent; Cascade is now the
"legacy Cascade agent". conforme keeps the `windsurf` id and targets the files
both agents read.

## Config files

| Feature | Path | Format |
|---------|------|--------|
| Rules | `.devin/rules/*.md` (preferred) or `.windsurf/rules/*.md` (legacy) | YAML frontmatter: `trigger`, `description`, `globs` |
| Skills | `.devin/skills/<name>/SKILL.md` (preferred) or `.windsurf/skills/<name>/SKILL.md` (legacy) | YAML frontmatter: `name`, `description` (both required) |
| MCP (Cascade) | `~/.config/devin/mcp_config.json` (user-global only) | JSON: `{ "mcpServers": { ... } }`. **Not project-scoped, so conforme does not generate it** |
| MCP (Devin Local) | `.devin/mcp_config.json` (project) | JSON: `{ "mcpServers": { ... } }`; remote uses `url` + optional `transport: http\|sse`. Not generated by conforme yet |
| Agents (Devin Local) | `.devin/agents/<name>.md` | YAML frontmatter: `name`, `description`, `model`, `allowed-tools`. Not generated by conforme yet |

## Activation modes

| Mode | Frontmatter |
|------|------------|
| Always | `trigger: always_on` |
| GlobMatch | `trigger: glob` + `globs: "**/*.ts, **/*.tsx"` |
| AgentDecision | `trigger: model_decision` + `description: "..."` |
| Manual | `trigger: manual` |

## conforme adapter

- File: `src/adapters/windsurf.rs`
- Detection: `.windsurf/`, `.devin/`, or a root `.windsurfrules`
- ID: `windsurf`
- Capabilities: activation_modes, skills
- No agents, no project-scoped MCP (`sync` warns that they are skipped for this target)
- General instructions -> `general.md` with `trigger: always_on`
- Rules and skills go under `.devin/` when the project has a `.devin/` directory, else under `.windsurf/`; `read()` follows the same precedence

## Notes

- Character limits: the global rules file is limited to 6,000 characters; workspace rules are limited to 12,000 characters **per file**
- The preferred rules path is `.devin/rules/*.md`, with `.windsurf/rules/*.md` (and root `.windsurfrules`) as a legacy fallback. After a migration to `.devin/`, the legacy `.windsurf/rules/` directory is also cleaned of orphans so the agent never sees two divergent copies of the same rule set
- Skills follow the same precedence: `.windsurf/skills/` is documented as legacy and is ignored once `.devin/skills/` exists ("the two are not merged"), so conforme writes skills to `.devin/skills/` whenever `.devin/` exists. Devin CLI also reads `.agents/skills/` first
- Manual-only skills in Devin CLI use `triggers: [user]`; Cascade documents no manual-only key. conforme writes the shared `disable-model-invocation: true` and does not emit `triggers` (known gap)
- Cascade's MCP config is user-global only, now at `~/.config/devin/mcp_config.json` (formerly `~/.codeium/windsurf/mcp_config.json`). Earlier conforme versions wrote a best-effort `.windsurf/mcp.json` that nothing consumed; a stale copy can be deleted by hand
- Devin Local reads a project-scoped `.devin/mcp_config.json` (and `.local.json`) and subagents from `.devin/agents/`. conforme does not generate them yet (known gap): Devin's own docs still disagree on the MCP path (the Devin Local page says `.devin/config.json`, the MCP configuration page says it moved to `.devin/mcp_config.json` in v3000.3)
- Devin Local also reads `CLAUDE.md`, `.cursor/rules/` and `AGENTS.md`; AGENTS.md at the root is always-on, and in a subdirectory it applies to `<dir>/**`
- Windsurf also has hooks and workflows but they are tool-specific, not synced
- The docs live at `docs.devin.ai` (the old `docs.windsurf.com/*` URLs redirect there); `cli.devin.ai/docs/*` redirects to `docs.devin.ai/cli/*`
- The documented `globs` example is a single pattern (`globs: **/*.test.ts`); conforme writes multiple patterns as a comma-separated string, the historical Windsurf form (unverified against the current agent)
